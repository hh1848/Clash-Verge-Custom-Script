# README 重构设计

## 目标

将项目 README 重构为面向 Mihomo / Clash Verge Rev 进阶用户的技术参考手册。在不改变脚本行为、不删除关键说明的前提下，提高首屏信息密度、章节检索效率、配置项可读性和效果展示质量，并将用户提供的五张截图全部纳入 README。

## 目标读者

- 已经了解 Clash Verge Rev、Mihomo、代理组和规则分流的用户。
- 希望快速判断脚本能力、完成安装，并继续修改策略组、DNS、TUN、节点过滤或链式代理配置的维护者。

## 范围与约束

- 仅修改 `README.md`，新增 `docs/images/` 下的五张截图以及本设计说明。
- 不修改 `mihomoScript.js` 的逻辑、默认值或第三方资源地址。
- 保留现有的重要免责声明、安全默认值、上游归属、规则来源和许可证提醒。
- README 继续以中文为主，技术名称、配置键与代码保持原文。
- 图片使用仓库相对路径，保证 GitHub 页面和本地 Markdown 预览均可显示。
- 五张图片按用户提供的原图使用，不裁剪、不压缩、不拼接。

## 信息架构

README 按以下顺序组织：

1. 项目标题、简短定位、兼容对象与免责声明。
2. 核心能力摘要，使读者快速了解全量覆写、应用分流、地区识别、GLOBAL、DNS/TUN 和安全默认值。
3. 目录，提供到主要技术章节的跳转。
4. 快速安装，包括复制脚本和 GitHub Raw 两种方式。
5. 效果预览，展示五张实际界面截图。
6. 策略组架构，集中说明基础组、应用分流组、地区组、默认选择与 GLOBAL 行为。
7. 网络与解析，说明直连模式、DNS、Fake-IP、TUN 和本机安全设置。
8. 节点处理，说明过滤、去重、地区识别、Emoji 补全、倍率组和 `dialer-proxy` 修复。
9. 配置参考，完整列出 `ruleOptionsEnable`、自定义节点和链式代理入口。
10. Rule Provider、注意事项、FAQ、项目结构、致谢、许可证与免责声明。

## 内容处理原则

- 合并当前重复或过度分散的策略组说明，使用表格集中表达组名、用途、默认选择与是否支持直连。
- 统一标题层级，避免一级标题和二级标题混用。
- 将安装步骤前移，删除“建议建立图片目录”等占位性文字。
- 保留必要代码块，但将简单枚举改为表格或紧凑列表，降低纵向篇幅。
- 不添加无法从脚本或现有 README 验证的性能、兼容版本或稳定性承诺。
- Raw 地址、上游项目和第三方规则源使用可点击链接。

## 验收标准

- README 中五张图片均能通过相对路径找到，标题与内容对应正确。
- README 不再含图片占位说明、待办文字或失效的目录链接。
- 标题层级连续，代码围栏成对闭合，表格列数一致。
- `ruleOptionsEnable` 中的配置项、脚本默认值、代理组名称和安全设置与 `mihomoScript.js` 保持一致。
- 安装步骤、Raw 地址、免责声明、上游致谢和许可证提醒完整保留。
- Git 状态中只出现本任务涉及的 README、五张图片和设计说明。

## 不在本次范围内

- 修改脚本功能、规则来源、默认代理组选择或网络参数。
- 新增 LICENSE、Release、CI、安装程序或自动更新机制。
- 对截图中的界面内容进行遮挡、标注或视觉编辑。
